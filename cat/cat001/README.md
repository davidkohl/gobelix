# ASTERIX Category 001 - Monoradar Target Reports

This package implements ASTERIX Category 001 (Monoradar Target Reports) according to the EUROCONTROL specification version 1.2.

## Purpose

Category 001 is used for transmission of monoradar surveillance data. It provides target reports containing:

- Target position in polar coordinates
- Mode-3/A and Mode-C codes
- Target quality indicators
- Track information (for radars with built-in trackers)
- Warning/Error conditions

## Plot vs Track UAPs

**Important:** CAT001 defines two distinct UAPs with incompatible FRN mappings:

| UAP Type | Use Case | FRNs |
|----------|----------|------|
| **Plot UAP** (default) | Raw radar detections | 15 |
| **Track UAP** | Radars with built-in trackers | 22 |

The FRN-to-DataItem mappings differ between UAPs. For example:
- FRN 3 in Plot UAP = I001/040 (Measured Position)
- FRN 3 in Track UAP = I001/161 (Track Number)

**Most radars send plot data.** Track data is typically generated by downstream tracking systems (which output CAT062). Use Track UAP only if your radar has a built-in tracker.

## Usage

```go
import (
    "github.com/davidkohl/gobelix/asterix"
    cat001uap "github.com/davidkohl/gobelix/cat/cat001/uap"
)

// For plot data (most common - this is the default):
uap, err := cat001uap.NewUAP12()      // or cat001uap.NewUAP12Plot()
if err != nil {
    // handle error
}

// For track data (only if your radar has built-in tracking):
uap, err := cat001uap.NewUAP12Track()
if err != nil {
    // handle error
}

// Create a decoder and register the UAP
decoder := asterix.NewDecoder()
decoder.RegisterUAP(uap)

// Decode messages
dataBlock, err := decoder.Decode(rawData)
```

## Measurement Units

- Range: 1/128 NM (nautical miles)
- Azimuth: 360°/65536 (approximately 0.0055°)
- Flight Level: 1/4 FL (25 feet)
- Time: 1/128 seconds since midnight UTC
